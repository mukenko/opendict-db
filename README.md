# opendict-db

국립국어원 **우리말샘**(https://opendict.korean.go.kr) Open API로 만드는 개인용 로컬 사전 DB입니다.
[stdict-db](../stdict-db), [urimal-history-db](../urimal-history-db)와 같은 구조를 따릅니다.

## 메모

- 표제어가 매우 많아(수백만 규모) 수집에 오래 걸립니다. 하루 호출 상한을 먼저 확인하고 이어받기를 전제로 설계합니다.
- 우리말샘은 사용자 참여형이라 변경·삭제가 잦습니다. 변경 감지 방식을 먼저 정합니다.
- urimal-history-db에서 검증한 수집·스키마 구조를 재사용합니다.
- 인증키는 `.env`에만 두고 저장소에 올리지 않습니다.

## 상태

폴더만 생성됨. 아직 코드 없음. urimal-history-db를 먼저 진행합니다.

## 데이터 출처

국립국어원 우리말샘. 이 저장소에는 코드만 올리고 사전 데이터는 포함하지 않습니다.
